FitFight

Design system

Every token and component the app is built from. Night is the primary theme; each colour carries its day-mode counterpart so a screen can be built either way from the same names. Interactive pieces below are live — drag the slider, open the drawer, fire a toast.

01 · Colour

Four families. Ink is every surface, Moss is you and winning, Ember is urgency and losing, Gold is progress only. Nothing else gets to be a colour.
