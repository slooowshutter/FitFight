# Screenshot index

Every PNG in this folder, what it shows, and what was tapped to get there.

**Capture settings**

| | `app/` | `system/` |
|---|---|---|
| What | The product mock | The style guide |
| Method | Clipped to the phone screen element | Full viewport |
| Logical size | 393 × 852 (iPhone 15/16 portrait) | 390 × 844 |
| Device scale | 2 → 786 × 1704 px | 2 → 780 × 1688 px |
| Base | Dark unless the name says `light-` | Dark unless the name says `light-` |
| Accent | Blue unless the name says `accent-` | Blue |

The `app/` shots are clipped to the device so there is no browser or gallery
chrome in frame — what you see is exactly what the screen should look like.
